|---|---|

| `requisitos.md` | 85 requisitos funcionais e 28 não funcionais |
| `modelo-de-dados-firestore.md` | Modelo de dados completo do Firestore e o script de carga (seção 8) |
| `regras-e-decisoes.md` | Regras de negócio e decisões de design (algumas são só do app) |
| `api-decisoes-tecnicas.md` | Stack e estrutura de pastas da API |
| `infra.md` | Infraestrutura, contas e nomes das variáveis de ambiente (sem valores secretos) |

Em caso de dúvida ou contradição entre eles, a decisão é do Gustavo.
